# tsshare Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static armv7 Go daemon that serves a folder or a zip as a read-only FAT32 virtual SD card (`share.vhd` on a FUSE mount) for TSConf's card 2.

**Architecture:** A `Source` yields a tree of `Node`s and reads file bytes. A `Volume` lays the tree out as MBR + FAT32 (contiguous extents, no stored FAT, directories synthesized on demand) and answers `ReadAt` over the virtual disk. `main.go` exposes one read-only FUSE file backed by `Volume.ReadAt`, reusing the spike's mount/signal/log code.

**Tech Stack:** Go 1.27, `github.com/hanwen/go-fuse/v2 v2.11.0` (v2.12.x does not build on 32-bit ARM), `fsck.vfat`/`mdir`/`mcopy` for validation, cross-build `GOOS=linux GOARCH=arm GOARM=7 CGO_ENABLED=0`.

**Spec:** `docs/superpowers/specs/2026-11-13-tsshare-design.md` (and the spike: `spikes/fuse-vhd/main.go`, `RESULTS.md`).

## Global Constraints

- Code in `tools/tsshare/` (own `go.mod`, module `tsshare`). Branch `tsshare`; commits `share: what`, local only, no push. Do not edit `sys/`, `rtl/`, `TSConf.sv`, or `spikes/`.
- Disk layout (from the owner's working `boot.vhd`): MBR, one FAT32 partition type `0x0C` starting at sector 128, 512-byte sectors, 4 KB clusters whenever the content allows at least 65525 clusters (smaller clusters below that; never above 4 KB unless 4 KB would exceed FAT32's cluster limit), 32 reserved sectors, 2 FATs, FSInfo, long file names + 8.3 aliases.
- Read-only: the FUSE file has mode 0444; a write returns EROFS. Reads past the end of the virtual disk return zeros.
- Never hang: every FUSE request is answered; a panic in a request is recovered and answered EIO; a source error gives EIO for that read only.
- Skip-with-warning rule (logged, never silent): files of 4 GiB or more, encrypted zip entries, duplicate paths (keep first), path entries with `..` or absolute paths, names over 255 UTF-16 units are truncated, a directory that would exceed FAT32's 2 MiB directory limit drops the excess entries.
- Limits to hit in tests: SD.zip (the owner's first source, `/mnt/nas/downloads/retro/retronas/mister/games/Spectrum/compilations/AAA/SD.zip`: 1.4 GB, 57,353 files, 1,033 dirs, depth 5, names up to 149 chars, 29 UTF-8 names, 57,221 deflated + 1,165 stored entries, largest entry 4.8 MB, 3.36 GiB uncompressed). Memory budget: whole daemon well under 150 MB on that zip; zip entry cache default 32 MB (lowered from 64 MB after the SD.zip memory measurements, see tools/tsshare/docs/PERF.md).
- Latency bars: warm 16 KB read about 1 ms or less; cold 3 MB read (a NAS-backed source) in under about 10 s.
- Board rules (`CLAUDE.md`): `root@192.168.1.15`, owner present, writes only where agreed, never touch `games/TSConf/*`, Frontier, `user-startup.sh`, `uartmode`; restore `menu.rbf`.

## Review Focus

- **Case-insensitive collisions:** a zip or folder holding `A.TXT` and `a.txt` (or `Readme` and `README`) in one directory must not produce two entries FAT cannot tell apart; test the chosen disambiguation.
- **8.3 alias storms:** many names sharing a stem ("XX S - ..." variants, 100+ in one directory) need `~1`...`~N` tails that shorten the stem as N grows and never repeat.
- **Odd names:** trailing dots/spaces, `:*?"<>|` and control chars, a leading dot, names with surrogate pairs (emoji), Cyrillic, 255+ units; all must round-trip or be sanitized with a warning.
- **Boundaries:** empty files (cluster 0), a file exactly one cluster long, an empty directory, a directory holding exactly the entries that fill a cluster, a directory near the 2 MiB limit.
- **Zip oddities:** backslash separators, `./` prefixes, entries with no directory records (synthesize parents), dates before 1980 (clamp) and with bad time fields, a corrupt entry (EIO on that read, daemon alive).

### Task 1: Names (8.3 aliases, LFN entries, sanitizing)

**Files:**
- Create: `tools/tsshare/go.mod`, `tools/tsshare/names.go`, `tools/tsshare/names_test.go`

**Interfaces:**
- Produces:
  - `func SanitizeName(name string) (clean string, changed bool)` replaces FAT-forbidden characters (`\ / : * ? " < > |` and control characters < 0x20) with `_`, trims trailing dots and spaces, truncates to 255 UTF-16 units without splitting a surrogate pair; `changed` is true if anything was altered. Empty result becomes `_`.
  - `type Namer struct{...}`; `func NewNamer() *Namer`; `func (n *Namer) Alias(long string) (short [11]byte)` returns a unique 8.3 alias within this Namer (one Namer per directory): NT style (upper-case, spaces/dots/forbidden removed, stem up to 6 chars + `~N`, extension up to 3 chars; a name that already fits 8.3 in a single case keeps its form without `~N`; the stem shortens as N reaches 10, 100, 1000, ...).
  - `func (n *Namer) Unique(long string) string` returns `long`, or `long` with a `~N` suffix before the extension if a case-insensitive twin was already seen in this Namer (so two entries never differ only by case).
  - `func LFNEntries(long string, short [11]byte) [][32]byte` returns the long-name directory entries in on-disk order (highest sequence first, last-entry flag 0x40), 13 UTF-16 units each, padded with 0x0000 then 0xFFFF, with the checksum of `short`. Empty slice if the name needs no LFN (fits 8.3 exactly, same case).
  - `func ShortChecksum(short [11]byte) byte`.

- [ ] **Step 1: Write the failing tests** in `names_test.go`: `TestSanitizeName` (table: forbidden chars, trailing dot/space, 300-char name, name ending in a surrogate pair at the cut, empty), `TestAliasNT` (table incl. `Readme.txt`→`README.TXT`... check the exact NT results: long names get `~1`, a name already 8.3 upper-case gets no tail), `TestAliasStorm` (200 names `XX S - Sword of Darkness (variant N).vgm` give 200 distinct aliases, all ≤ 8+3, tails correct), `TestUniqueCase` (`A.TXT`, `a.txt`, `A.txt` give three names no two equal case-insensitively), `TestLFNEntries` (a 20-char and a 255-char name: entry count, sequence/last flag, UTF-16 packing, checksum equals `ShortChecksum`).
- [ ] **Step 2: Run** `cd tools/tsshare && go test ./... -run 'Name|Alias|Unique|LFN'` and confirm failure (undefined).
- [ ] **Step 3: Implement** the functions above in `names.go` (module `tsshare`, `go 1.27`, no external dependencies yet).

### Task 2: Volume (layout, directories, FAT, ReadAt)

**Files:**
- Create: `tools/tsshare/source.go` (types only), `tools/tsshare/volume.go`, `tools/tsshare/volume_test.go`, `tools/tsshare/testutil_test.go`

**Interfaces:**
- Consumes: Task 1's `Namer`, `LFNEntries`, `SanitizeName`.
- Produces (`source.go`):
  ```go
  type Node struct {
      Name     string
      IsDir    bool
      Size     int64       // files
      ModTime  time.Time
      Children []*Node     // dirs
      ID       int         // set by the Source; opaque to Volume
  }
  type Source interface {
      Tree() (root *Node, warnings []string, err error)
      ReadFileAt(n *Node, p []byte, off int64) (int, error)
      Close() error
  }
  ```
- Produces (`volume.go`):
  ```go
  type VolumeOptions struct{ Label string; PartStartSector int /*default 128*/; SectorsPerCluster int /*0 = auto*/ }
  func NewVolume(src Source, opt VolumeOptions) (*Volume, []string /*warnings*/, error)
  func (v *Volume) Size() int64                                  // virtual disk size in bytes, a multiple of 512
  func (v *Volume) ReadAt(p []byte, off int64) (int, error)      // fills p completely; zeros beyond Size and in unallocated space; error only if a source read fails
  ```
  Allocation is deterministic: root dir, then every directory (breadth-first, children sorted case-insensitively by name), then files in the same order, each as one contiguous extent. No stored FAT: FAT sectors are computed from the extent table by binary search. Directory sector bytes are produced on demand from the tree plus the `Namer`s (alias assignment is computed once per directory and kept in a compact form, not recomputed per read). `.` and `..` entries as FAT specifies (`..` of a first-level directory has cluster 0). Dates from `ModTime`, clamped to 1980-2107.

- [ ] **Step 1: Write `testutil_test.go`**: an in-memory `Source` built from a Go map (path → bytes, plus modtimes), and helpers `dumpVolume(t, v) string` writing the whole virtual disk to a temp file, `fsck(t, path)` running `fsck.vfat -n` on the partition (extract with `dd skip=128`, since `fsck.vfat` has no `--offset`) and failing on any message, `mdirList(t, path)` and `mcopyOut(t, path, "::dir/file")` using `mdir/mcopy -i <img>@@65536`. Skip the test with a clear message if `fsck.vfat`/`mtools` are missing.
- [ ] **Step 2: Write the failing tests** in `volume_test.go`: `TestMBRAndBootSector` (signature 0x55AA, partition type 0x0C, start 128, FSInfo signatures, 2 FATs identical, volume label), `TestSmallTree` (fixture: `/HELLO.TXT`, nested dirs 3 deep, a 0-byte file, a file of exactly one cluster, a file of cluster+1 bytes, an empty directory, unicode names incl. Cyrillic and an emoji, names differing only by case): `fsck` clean, every file's bytes equal the source via `mcopy`, directory listing names equal the source (after sanitizing), `TestSectorsPerCluster` (tiny tree gives clusters ≥ 65525 with 512-byte clusters; a tree of about 300 MB gives 4 KB clusters; a forced value is honored), `TestReadAtAnyRange` (random offsets and lengths 1..40000 over the whole dump equal a straight read of the dump file; reads past Size are zeros), `TestDirectoryLimit` (a directory with 70,000 children is truncated to the FAT32 limit with a warning, fsck clean), `TestSourceError` (a source that fails one file's read returns an error for reads in that file's extent only).
- [ ] **Step 3: Run** `go test ./... -run 'MBR|Small|SectorsPer|AnyRange|DirectoryLimit|SourceError'` and confirm failure.
- [ ] **Step 4: Implement `source.go` and `volume.go`** per the interfaces. Keep the extent table and per-directory data compact (target: under about 300 bytes per node; SD.zip has 58k nodes).
- [ ] **Step 5: Run** the tests; all pass, `go vet ./...` clean.

### Task 3: Sources (directory and zip) with caches

**Files:**
- Create: `tools/tsshare/dirsource.go`, `tools/tsshare/zipsource.go`, `tools/tsshare/cache.go`, `tools/tsshare/sources_test.go`

**Interfaces:**
- Consumes: `Source`, `Node` (Task 2).
- Produces:
  - `func NewDirSource(root string, o SourceOptions) (Source, error)`; `func NewZipSource(path string, o SourceOptions) (Source, error)`; `type SourceOptions struct{ CacheMB int /*default 64*/; FDLimit int /*default 64*/ }`.
  - `func OpenSource(path string, o SourceOptions) (Source, error)` picks by whether `path` is a directory or a `.zip` file.
  - Dir source: recursive scan (symlinks to files followed, symlinked directories skipped with a warning, unreadable entries skipped with a warning), files opened lazily through an LRU of at most `FDLimit` descriptors, plus a per-file read-ahead window of about 256 KB (a read inside the window is a memory copy; a read outside refills it).
  - Zip source: reads the central directory once; names decoded as UTF-8 when the flag is set, otherwise CP437; backslashes become `/`; leading `./` and `/` stripped; entries containing `..` skipped with a warning; directories synthesized for entries without directory records; duplicates keep the first; encrypted and 4 GiB+ entries skipped with warnings. Stored entries are read with `ReadAt` on the archive; deflated entries are inflated whole on first access into an LRU of total `CacheMB` (entries larger than the budget stream from the start through a sliding window and restart on a backward seek). A corrupt entry returns an error for that read only.

- [ ] **Step 1: Write the failing tests** in `sources_test.go` (fixtures built in `t.TempDir()`): `TestDirSourceTree` (nested dirs, symlink file followed, symlinked dir skipped with a warning, unreadable file skipped), `TestDirSourceReadAt` (random ranges equal the file; more files than `FDLimit` all readable), `TestZipSourceTree` (backslash names, `./` prefix, no directory records, `..` entry skipped, duplicate path keeps the first, CP437 name without the UTF-8 flag, encrypted entry skipped), `TestZipReadAt` (stored and deflated entries, random ranges, backward seeks, an entry bigger than `CacheMB` streams correctly), `TestZipCorruptEntry` (flipped byte in a deflated entry: error on that file, other files fine), `TestCacheBudget` (reading many entries never exceeds the budget by more than one entry).
- [ ] **Step 2: Run** `go test ./... -run 'DirSource|ZipSource|ZipRead|ZipCorrupt|CacheBudget'` and confirm failure.
- [ ] **Step 3: Implement** the three files; the zip source uses `archive/zip` and `compress/flate` from the standard library.
- [ ] **Step 4: Run** the tests; pass; `go vet ./...` clean.
- [ ] **Step 5: Whole-volume check from each source:** add `TestVolumeFromDirAndZip` building the same tree as a directory and as a zip, asserting both volumes are byte-identical (modulo nothing: same layout) and pass `fsck`.
- [ ] **Step 6: Commit** `share: directory and zip sources with caches`.

### Task 4: Daemon (FUSE, flags, shutdown, logging)

**Files:**
- Create: `tools/tsshare/main.go`, `tools/tsshare/log.go`, `tools/tsshare/main_test.go`, `tools/tsshare/.gitignore` (binaries, `*.img`, `*.log`)
- Reuse from: `spikes/fuse-vhd/main.go` (mount with `DirectMount` as root else fusermount3 path, one-file filesystem, two-stage signal handling with lazy unmount, early signal handler, non-blocking read log with `O_TRUNC`, EIO for non-EOF errors)

**Interfaces:**
- Consumes: `OpenSource`, `NewVolume`, `Volume.Size`, `Volume.ReadAt`.
- Produces: binary `tsshare -src <dir|zip> -mount <dir> [-label NAME] [-cache-mb N] [-log file] [-v]`. Mounts a FUSE filesystem with one file `share.vhd`, mode 0444, size `Volume.Size()`; reads call `Volume.ReadAt`, recovering any panic to EIO. Startup prints one line per warning count and the volume geometry (clusters, cluster size, disk size, node count) and fails with a clear message if the source cannot form a valid FAT32 volume. `-v` writes the per-read log in the spike's format (`ts_ns offset len backing|synthetic|error lat_us`) through a non-blocking channel writer.

Skip with a clear message if `/dev/fuse` or `fusermount3` is unavailable.
